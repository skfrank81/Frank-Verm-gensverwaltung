Grundsätzliches

Diese Website verwendet keine Cookies, keine Analyse- oder Tracking-Werkzeuge und keine Kontaktformulare. Schriftarten und Bilder werden direkt von diesem Server geladen; es werden keine Inhalte von Drittanbietern eingebunden.

Hosting über GitHub Pages

Diese Website wird über GitHub Pages gehostet, einen Dienst der GitHub Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. Beim Aufruf der Website erfasst GitHub automatisch Informationen in sogenannten Server-Logfiles, insbesondere die IP-Adresse, Datum und Uhrzeit des Zugriffs, die aufgerufene Seite sowie Browser- und Betriebssysteminformationen.

Diese Daten dienen der technischen Bereitstellung, Stabilität und Sicherheit der Website. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO; unser berechtigtes Interesse liegt in einer sicheren und zuverlässigen Bereitstellung der Website.

GitHub kann diese Daten auch auf Servern außerhalb der Europäischen Union, insbesondere in den USA, verarbeiten. GitHub ist nach dem EU-U.S. Data Privacy Framework zertifiziert, auf dessen Grundlage ein angemessenes Datenschutzniveau besteht (Art. 45 DSGVO). Weitere Informationen: Datenschutzerklärung von GitHub.

Kontakt per E-Mail

Wenn Sie uns per E-Mail kontaktieren, verarbeiten wir Ihre Angaben ausschließlich zur Bearbeitung Ihrer Anfrage. Rechtsgrundlage ist Art. 6 Abs. 1 lit. b bzw. lit. f DSGVO. Die Daten werden gelöscht, sobald sie für die Bearbeitung nicht mehr erforderlich sind und keine gesetzlichen Aufbewahrungspflichten entgegenstehen.
